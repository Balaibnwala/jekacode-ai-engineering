# Projects folder

This is where **you** put your work.

The weekly lesson folders (`week01-...`) are the classroom. Do not pile finished homework inside those folders. Copy your project into here so teachers can find it, and so you can push it to GitHub.

## First time

1. Inside `projects/`, create a folder with your **GitHub username**
2. Copy `_template/` into that folder if you want a ready-made shape
3. Put each week's project in the matching week folder

**Filled sample (copy the shape, not the words):** [solarinayo/](solarinayo/)

```
projects/
  solarinayo/          ← example pack (this repo)
    README.md
    week01/ … week12/
    week02/student_analyzer.py
    capstone/
  YOUR_GITHUB_USERNAME/
    README.md
    week01/
    week02/
    capstone/
```

## Every week

1. Finish the class project
2. Copy it into `projects/YOUR_NAME/weekXX/`
3. Write 5 lines in that week's README:
   - What I built
   - Who it helps
   - How to run it
   - What was hard
   - What I would improve

## Capstone

Put your final product in `projects/YOUR_NAME/capstone/`.

## GitHub

Follow [../guides/fork_push_pr.md](../guides/fork_push_pr.md): fork the class repo, commit only `projects/YOUR_NAME/`, push, open a Pull Request if the teacher asks.

## Do not put here

- Your `.env` file
- API keys
- Giant video files
- `venv` folders
