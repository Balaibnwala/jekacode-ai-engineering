# Jekacode programme handbook (sample knowledge)

This file is used in Week 6. Students chat with it, like a school textbook.

## What is Jekacode?

Jekacode is a technology training company in Africa. We teach practical skills so beginners can build real products.

## The AI Engineering programme

The Jekacode AI Engineering Cohort is a 12-week beginner programme. Students start with little or no coding experience. They finish by building and deploying AI applications.

## Tools we use

- VS Code, Python, Ollama, Gemini, DeepSeek, Hugging Face, Gradio, Streamlit
- HTML/CSS chat for a real frontend

We do not use OpenAI or OpenRouter in this classroom.

## Weekly rhythm

Each week has **three live classes** (see it, type it, ship it). Full map: the course `guides/THREE_CLASSES.md` file.

## Capstone rule

Do not start with "I want to build an AI app." Start with a problem:

1. Who has the problem?
2. How often does it happen?
3. How do they currently solve it?
4. Why is the current solution not good enough?
5. Can AI actually improve it?
