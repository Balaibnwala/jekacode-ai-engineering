JEKACODE · TRADE-OFFS

Normal software engineering vs AI engineering

Normal software engineer

  • Input: exact rules. If score ≥ 50, print Pass.
  • Output: the same every time (mostly).
  • Bugs: you can often point at one line.
  • Tests: 2 + 2 must be 4.
  • Example: student analyzer in Week 2.

AI engineer

  • Input: messy language, documents, goals.
  • Output: useful, but not identical every time.
  • Bugs: hallucination, leaked secrets, ignored rules.
  • Tests: try normal / bad / confusing input (Week 11).
  • Example: study assistant that explains photosynthesis.

The honest trade-off

AI is wonderful when the job is language: explain, draft, search a handbook, classify an email.

Ordinary code is better when the job is money, marks, or “must be exact”: fees, exam scores, BVN, doses.

Jekacode rule: use Python for the rules. Use Gemini / Ollama for the words. Combine them. That mix is AI engineering.
