How people normally ask AI — and how we engineer it

Normal chat (weak)

write about python

Works a bit. Vague. Random length. Maybe American examples. Maybe invents a library that does not exist.

Engineered prompt (strong)

You are a Python instructor for JSS2 in Lagos.
Explain Python using a school result sheet.
Under 120 words. Simple English.
Do not invent library names.

Role + place + example + limit + safety. This is prompt engineering.

How an AI engineer goes further

  1. Keep the prompt in code (so the shop app always uses it).
  2. Add a system message (job description) separate from the user’s question.
  3. Chain steps: first list problems, then write one caption.
  4. Ground answers in a document (RAG, Week 6) so it stops guessing school rules.
  5. Test bad input (Week 11). ChatGPT-the-website will not do that for your users.
