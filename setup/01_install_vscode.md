# Step 1 — Install VS Code

VS Code is a free app from Microsoft. It is where you will write Python, open notebooks, and run your AI apps.

We use **VS Code**, not Cursor, for this programme.

## Download

1. Open your browser.
2. Go to [https://code.visualstudio.com](https://code.visualstudio.com)
3. Click **Download**.
4. Install it like any other app.
5. Open VS Code.

## Open this course

1. In VS Code, choose **File → Open Folder…**
2. Select the folder called `jekacode-ai-engineering track` (this course).
3. If VS Code asks "Do you trust the authors?", click **Yes**.

## Install 2 extensions

On the left, click the square **Extensions** icon.

Search and install:

1. **Python** (publisher: Microsoft)
2. **Jupyter** (publisher: Microsoft)

When VS Code suggests them at the bottom right, you can click **Install** there too.

## How you will work each week

- A **notebook** looks like `day1.ipynb`. Click it. Click a cell. Press **Shift + Enter** to run it.
- A **Python app** looks like `study_assistant.py`. You run it in the Terminal.

You are done with Step 1. Next: [02_python.md](02_python.md)
