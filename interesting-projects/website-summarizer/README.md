# Website summarizer

Classic LLM-engineering exercise: fetch a public page, strip junk HTML, send text to Gemini.

**User story:** I want to paste a news or Jekacode URL and get five bullets.

```bash
python interesting-projects/website-summarizer/summarize.py
```

Only summarise **public** pages you are allowed to read. No logins, no paywalls, no stealing.
