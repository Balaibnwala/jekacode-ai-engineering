# 12-week roadmap

This is the map on the wall. Students follow the week folders and [guides/HOW_TO.md](guides/HOW_TO.md).

**Level:** complete beginners, first time coding.  
**Editor:** VS Code.  
**Rhythm:** **3 classes per week** — [guides/THREE_CLASSES.md](guides/THREE_CLASSES.md).  
**Models:** Ollama (local first), **Gemini**, **Grok**, DeepSeek, Hugging Face. No OpenAI. No OpenRouter.

## How a week works (3 class files)

| File | Class | What happens |
|---|---|---|
| `day1.ipynb` | 1 See it | Theory + terms (~2h) |
| `day2.ipynb` | 2 Type it | Lab (~2h) |
| `day3.ipynb` | 3 Ship it | Project + git (~2h) |

## The climb

```
Week 1–2   Words + Python baby steps
Week 3–4   Talk to AI from code, then give it a screen
Week 5–7   Prompts, documents (RAG), one agent
Week 8–9   Automation + pick a real African problem
Week 10–12 Live app, safety tests, capstone demo
```

## Module outcomes

### Weeks 1–2 · Foundations
Students can say, in their own words: AI is the field, generative AI makes content, an LLM predicts useful language, an AI Engineer builds products. They can write a small Python programme: input → process → output.

### Weeks 3–5 · First products
Students call Gemini and DeepSeek, keep keys in `.env`, and ship a Streamlit study assistant plus a prompt-based business assistant.

### Weeks 6–8 · Systems
Students connect answers to documents (RAG), let one agent use one or two tools, and design a trigger → AI → action workflow in n8n.

### Weeks 9–12 · Product and career
Students validate a local problem, deploy, test for hallucinations and prompt injection, then present a capstone.

## Do not skip

- Week 2 (Python). Slow is kind.
- Week 6 (RAG analogy) before any vector-database words.
- Week 9 problem questions before anyone names a tech stack.

## Teacher one-week-ahead rule

You should always have built the **student project** yourself before class, then a slightly harder **teacher version**. You stay one project ahead, not “master of all AI.”
